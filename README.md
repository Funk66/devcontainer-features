# devcontainer-features

A collection of [dev container](https://containers.dev) [Features](https://containers.dev/implementors/features/).

## Features

| Feature                  | Description                                                                                                                                                                                                                  |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`opencode`](./opencode) | Configures [opencode](https://opencode.ai) to talk to a local, OpenAI-compatible endpoint (LM Studio / Bionic) by default. Delegates the binary install to the community `opencode.ai` feature (listed via `installsAfter`). |
